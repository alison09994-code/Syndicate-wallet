SYNDICATE Wallet — phone-first PWA prototype

This is a free, installable-web-app prototype for iPhone. It is not a native App Store app and is not a functioning crypto wallet yet. All send/receive actions are disabled; the QR is a placeholder; balances are zero.

To put it on your iPhone for free:
1. Upload these four files to a new public GitHub repository using Safari (github.com).
2. In the repository, open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
4. Wait for GitHub Pages to publish the site.
5. Open the published HTTPS address in Safari on your iPhone.
6. Tap Share > Add to Home Screen.

GitHub Pages offers free static hosting for public repositories. No monthly subscription is needed for this prototype. A domain name is optional and may cost money, so do not buy one.

For production crypto use, an audited wallet SDK, secure key lifecycle, transaction signing, selected USDT network(s), independent security review, and compliant service integrations are still required. Never enter a real seed phrase into this prototype.
